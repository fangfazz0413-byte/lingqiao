# 灵桥数据层

`.bridge/` 文件夹是灵桥在这台电脑上的数据，不进 Git。下面提到的 `bridge_state.py`、`sync.py`、`zcode_inject.py` 都在 `app/` 里。

同步、删除、恢复应优先通过会话桥App执行。旧 `sync.py` 自动互注入口已停用，`--export-only`只导出最近3天文字，避免绕过可恢复操作。

`bridge_state.py`统一原子JSON写入、0600权限、同线程可重入的跨进程操作锁。`ledger.json`表示当前同步状态，`provenance.json`持久保存来源关系，删除来源也保留目标墓碑。禁止把老ledger备份直接覆盖当前状态。

ZCode App/CLI共享version2清单，包含数据库path/device/inode身份和会话状态。`--db /tmp/lab.sqlite`的清单/账本在labs/<identity>/内，不能清掉真库账本。CLI验证在SQL提交前进行，并记录prepared/committed；异常回滚或补偿。回滚走可恢复删除并只处理对应清单记录，保留历史状态。

- `.bridge/operations/<id>/journal.json`：新版操作记录与数据库恢复材料。
- `.bridge/cleanup-plans/<id>.json`：15／30天闲置清理的私有签名预览计划，5分钟有效；重启后需重新预览。
- `.bridge/trash/`：旧回收材料保留，完整性未知，不自动完整恢复。
- `.bridge/details/`：私有文字分页缓存，可重建，不是原始数据。
- `.bridge/instance.json`：运行中的实例凭据，不可公开。
- `.bridge/config.json`：`sync_window_days`默认3。

旧ZCode整库快照只代表快照时间，覆盖会丢弃之后的合法新会话。不要把整库替换当日常撤销方法。

同步仅搬运约定的真人/AI文字；系统块精确剥离，HTML/XML与文件引用后的真实请求保留。附件、工具事件不在转换支持范围内。归档、子代理、缺文件条目分别标记；列表搜索只查标题/目录。

批量清理调用同一可恢复删除流程，持有操作锁，并在备份前后核验活动指纹。外键CASCADE与SET NULL分别保存／恢复，触发器只在相关写入事务内暂时暂停。冲突或补偿材料不完整时停止覆盖，保留操作材料供复核。
